# Dice Roll

A React and TypeScript dice roller built with Vite.

Styles use Sass. Vite's built-in CSS Modules support is available by naming
component styles `Component.module.scss`; global styles can use `.scss` files.

## Development

```sh
yarn install
yarn dev
```

## Scripts

- `yarn dev` starts the Vite development server.
- `yarn build` creates a production build.
- `yarn typecheck` runs strict TypeScript checks.
- `yarn lint` checks JavaScript, TypeScript, and JSX with ESLint.
- `yarn format` formats supported files with Prettier.
- `yarn format:check` checks formatting without changing files.

Husky runs ESLint with fixes and Prettier on staged files before each commit.
